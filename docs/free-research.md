# 不依赖 AIsa 的每日资讯工作流

用户目标：持续获得覆盖较广、中文可读、能用于 AI 视频和自媒体创作的消息。默认只用公开免费数据及现有 Codex 订阅额度。不得调用 AIsa、购买其它数据 API 或自动充值。

## 两种入口

- 网页“更新并生成选题”或 `npm run refresh`：刷新已启用 RSS/Atom，补充近期中文翻译，读取候选原文，生成带来源的中文机会和站内通知。
- 每日北京时间 08:00 的 Codex 自动化：先主动检索公开网页补漏，再将结果导入同一数据库，最后运行以上刷新入口。网页按钮本身不启动 Codex App 的搜索工具；需要即时主动搜索时，可在此 Codex 任务说“现在按免费工作流搜索并更新平台”。

电脑须开机、保持唤醒、网络可用，Codex App 运行且账号有可用额度。本地运行指程序和资料存储在电脑，Codex 模型仍联网；不等于离线大模型。单个来源失败不阻断其它来源，已保存的内容、译文和收藏保留。

## 主动检索范围

每轮检查以下四组，按保存的推荐偏好加权。以过去 24 小时的新消息为主、近 7 天实用资料为补充。每轮显式检查 GitHub 项目和发布记录、X 可访问公开帖子、YouTube 公开视频页面及相关网站。遇到真正有价值的旧教程可入资料库，保留原日期；不要改成今日新闻。

| 方向 | 固定关注对象及查找方式 | 取舍 |
| --- | --- | --- |
| AI 视频和短剧 | ComfyUI、Runway、Luma、可灵、海螺、Vidu、PixVerse；官网新闻、教程、发布记录、公开演示页面 | 找实际可用变化、角色一致性、分镜衔接、生成与剪辑工作流；区分研究预览和已上线功能 |
| 图像、配音、字幕 | fal、Replicate、Hugging Face、Diffusers、ElevenLabs、HeyGen；博客、GitHub Releases、文档更新 | 优先本地可运行或能节省制作步骤的能力；不把读取免费资讯说成工具使用免费 |
| 产品和工具 | OpenAI、Anthropic/Claude、Google/DeepMind、Codex、Gemini CLI；官网、帮助中心、GitHub | 产品变化和对普通使用者有影响的修复；忽略纯版本号、每日构建和售票宣传 |
| 中文实践和补充证据 | 量子位、少数派、InfoQ；公开搜索、Reddit 创作社区、可访问的 YouTube/B站视频页面、用户提供的公众号或X链接 | 媒体报道回查原始出处；社区经验标明作者个人说法；只有标题或搜索摘要时只是线索 |

使用 Codex 当前可用的网页搜索先发现链接，再打开对应原始页面。没有搜索工具时，可读取已知官网的新闻/更新列表；动态页面必要时用浏览器。公开视频存在字幕时才读取字幕；只看到标题、描述不能声称看完视频。登录墙、验证码、付费墙和无法访问的页面记入覆盖限制，不绕过，也不切到付费接口。X可查到的公开帖子作为补充线索，不能承诺全站实时热榜或完整互动数据。

每轮建议 6–10 个有针对性的检索，不堆砌同义查询。至少覆盖视频、音频/图像、产品工具、中文实践四组；通常保留 5–12 条新增、可用的页面，允许实际没有新消息。按事件合并多篇报道，少而有用的推荐优先于填满日报。

## 写入与事实边界

主动搜索产物使用 `scripts/import-research.mjs` 的 schemaVersion 1 合同，运行 `npm run research:import -- data/research-input/文件.json`。公开标题和摘要与中文整理分开存储。每条记录必须保留原始链接、来源名称、实际检索时间、原始证据片段；发布时间未知为 null，只有日期时不要自造小时和时区。

导入器对 `original-page` 重新访问原始链接并匹配引文；只有搜索摘要、页面失败或引文不匹配的记录降为待核验线索。页面引文匹配只证明发布者写过，不证明厂商效果、收益或社区经验真实。导入器不调用模型、AIsa，也不发送外部消息。

在 `data/research-input/` 保存本轮输入，并另存同名 `-coverage.json`：检索时间、检查的四组、查询词、实际打开的链接、成功/失败/无新增情况、未覆盖部分。不要保存登录凭据或浏览器私人页面。空结果也保留覆盖记录，不伪造已检查未打开的来源。

导入后运行 `npm run refresh`，等待明确终态；有正在进行的任务时等它结束再导入，不与更新并发。一次刷新未完成时只查任务状态，不重复提交。原文、中文摘要、是否值得做和建议角度在界面分开；翻译有缓存，历史外文可逐条补译。

阅读区每栏最多 6 条完整中文线索，同一事件不跨栏重复；同一来源每栏最多三条，同一项目的版本流最多保留两条，纯版本、求助、无实质摘要、普通 VR 展示不凑进精简视图。标题与摘要须分别为简洁中文，展开后仍为中文，原文语言只在主动查看原文时显示。尚未补译的内容留在全部资料，并明确剩余数量。

日报最多 5 条重点和 3 个创作方向，每条回答：发生了什么、对我的制作有什么用、可以怎么实测或讲清楚、原始来源是什么、还有什么未验证。只有实质新内容或故障/需处理事项才提醒；不是每天必须凑新闻。

今日机会默认展示本日首次入选的内容；早前已推荐的 URL 放入“继续跟进”，保留首次推荐日期和原文发布时间。没有新增时明确显示空态，不把旧选题换标题再次当新机会。JSON、Markdown 同样区分新增与继续跟进。
